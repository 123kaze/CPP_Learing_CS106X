# 两资产 ETF v1：未来纸面跟踪协议

开始日期：2026-10-13（下一共同交易日）。该文件冻结纸面记录规则；不产生真实订单。

1. 虚拟初始资金 20,000 元；以 2026-10-13 开盘价，在可用现金及佣金约束下尽量建立
   510300 与 518880 各约 50% 的 100 份整手仓位。
2. 每个自然季度的第一个共同交易日开盘按同一规则再平衡；季度内不因涨跌调整。
3. 佣金万 2.5、每笔最低 5 元、卖出印花税 0；记录开盘价、份额、现金、佣金和收盘净值。
   同时以另一笔独立的 20,000 元虚拟账户，在相同起始日开盘买入 510300 后持有，作为基准；
   它不与策略账户共用现金，也不参与再平衡。
4. 连续记录至少 12 个季度。中途任何正负收益都不改变权重、频率或资产；否则本验证作废。
5. 每个两只 ETF 的共同交易日收盘后运行一次，才能得到真实的日度最大回撤；漏掉普通估值日
   可在下次继续，但必须在最终报告中披露缺失日、不能声称最大回撤精确。一旦跳过季度首个
   共同交易日，账本会拒绝事后按已知价格补录，该次前瞻验证作废。
6. 到期后比较年化收益、最大回撤、实际成交成本及 510300 同期买入持有。其结果才是独立的
   前瞻验证证据；在此之前，禁止用历史曲线替代真实未来表现。

收盘后使用 `paper_two_asset_tracker.py` 记录，不会触发券商订单：

```bash
# 先预览；确认纸面成交后才加 --commit
python paper_two_asset_tracker.py --as-of 20261013
python paper_two_asset_tracker.py --as-of 20261013 --commit

# 只读地汇总组合与 510300 买入持有基准；不会下单或修改账本
python paper_two_asset_report.py
```

跟踪器使用**未复权**开盘/收盘价，并默认从新浪 ETF 的累计分红表自动把 510300 的分红
增量记入现金；`518880` 当前没有该表记录。若数据源失败或与券商到账不符，可用
`--dividend-cash 实际金额` 添加校正现金，或以 `--no-auto-dividends` 完全手工记录。不能把
前复权价格当作真实成交价。它会拒绝事后补录起始日或重复日期，以保证前瞻记录的时间顺序。
基准账户的手工分红校正应单独用 `--benchmark-dividend-cash 实际金额`；组合和基准持仓不同，
不能把一个总金额机械复制到另一账户。

每笔分红、买卖金额与佣金均写入 CSV；`paper_two_asset_report.py` 基于实际 MARK 记录给出
组合/基准年化、最大回撤、相对收益与累计费用。若普通估值日缺失，报告会明确提醒最大回撤
仅基于已记录日期。
