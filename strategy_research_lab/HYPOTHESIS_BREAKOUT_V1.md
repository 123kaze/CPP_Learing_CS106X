# 候选二：中期相对强度的新高突破（预先登记，v1）

登记日期：2026-10-12。此文件先于代码与结果存在；目的不是承诺收益，而是让这一个和
“回踩 EMA/AVWAP”不同的假设能够被证伪。

## 经济假设

中期动量可能在信息缓慢扩散或投资者锚定下延续；若个股在剔除最近一个月后仍明显强于
市场、以放量创阶段新高的方式确认，随后一段时间的趋势延续或许足以覆盖交易成本。它和
被淘汰的“上涨后回踩到 EMA/AVWAP”不同：这里不押注支撑位反弹，而只在新高确认后进入，
并使用让盈利持仓继续运行的追踪止损。

这是可检验假设，不是关于未来价格的断言。动量文献同时指出存在崩盘风险，因此市场状态
和仓位风险限制属于假设的一部分，而不是事后补丁：

1. Jegadeesh 与 Titman（1993），[Returns to Buying Winners and Selling Losers](https://doi.org/10.1111/j.1540-6261.1993.tb04702.x)，是中期赢家组合假设的经典起点。
2. Moskowitz、Ooi 与 Pedersen（2012），[*Time Series Momentum*](https://doi.org/10.1016/j.jfineco.2011.11.003)，支持将趋势延续作为跨资产的可证伪研究对象，但不证明 A 股个股一定有效。
3. Daniel 与 Moskowitz（2016），[*Momentum Crashes*](https://doi.org/10.1016/j.jfineco.2015.12.002)，说明动量具有左尾风险；因此不能因一个上涨年份的收益就放松止损、费用或涨跌停成交假设。

## 一次性固定规则

以下常数一经登记不得根据 2022 年之后的结果搜索或修改：

| 项目 | 固定规则 |
|---|---|
| 股票池 | 当前主板 A 股；名称含 ST/退剔除（仍披露其未来信息偏差） |
| 相对强度 | 信号日 `close[t-20] / close[t-120] - 1` 取全市场前 10% |
| 个股趋势 | 收盘 > EMA50 > EMA200 |
| 突破确认 | 收盘创前 55 日（不含当天）新高；当日成交量 >= 前 20 日平均的 1.5 倍 |
| 市场状态 | 中证全指收盘 > EMA200，且过去 20 日收益 > 0 |
| 进场 | 次日触发价（信号日高点 + 0.01）成交；高开超过 1% 不追；一字涨停不假设能买进 |
| 初始止损 | 触发价 - 2 × 信号日 ATR14 |
| 出场 | T+1 起按 `max(初始止损，前一交易日为止的最高价 - 3 × 前一日 ATR14)`；持有 40 个交易日到期按收盘；跳空和一字跌停按与候选一相同的保守规则 |
| 组合 | 单笔风险 0.5% 账户、最坏跳空 10%、整手、最多两只持仓；同日按中期强度由高到低取两只 |
| 成本 | 双边佣金万 2.5、单边最低 5 元、卖出印花税千 0.5 |

上述 55/120/20 日窗口是预先固定的、易解释的中期定义，**不是**通过网格搜索得到的最佳点。

## 检验纪律

1. 先只在 2022-01-01 至 2024-12-31 形成期运行一次；若该期扣费后平均 R <= 0、交易少于
   40 笔，或任何自然年平均 R <= 0，直接拒绝，不查看本假设的 2025 年后输出。
2. 只有形成期达到上述门槛，才运行一次 2025-01-01 至 2026-06-30 的样本外检验。
3. 样本外通过标准沿用：每个自然年平均净 R > 0，整体平均净 R >= 0.2，且交易笔数 >= 20。
4. 无论结果如何，都不得再使用 2025 年后的数据回改本 v1；新想法必须另建 v2 文件并重新
   登记，不能把 v1 的失败伪装成“微调”。

## 可复现命令

```bash
cd strategy_research_lab
python breakout_backtest.py --start 20220101 --end 20241231 --holdout-start none \
  --output-dir results/breakout_v1_formation

# 仅当前一条形成期门槛通过才允许运行：
python breakout_backtest.py --start 20250101 --end 20260630 --holdout-start 20250101 \
  --output-dir results/breakout_v1_oos
```

`breakout_backtest.py` 复用父目录的腾讯缓存和同一套成本、T+1、整手及涨跌停成交处理；
EMA200 要求至少 200 根日线预热，因此在现有缓存从 2021-06-15 起的情况下，2022 年最初
约数月自然不会有信号；这会在输出中披露，而不能被解释为零交易。它是研究脚本，不能接到
实盘选股器，除非先通过这一完整流程。
