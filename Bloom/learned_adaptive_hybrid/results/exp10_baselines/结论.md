# 实验 10：与基线对比（2026-10-28）

脚本：`src/exp10_baselines.py`。表格见 `report.md` 和 `summary.json`，图见 `figures/fig13`（PLBF 0% 缓存的点截断在 2000× 处显示）。

## 设置

- **范围**：4 个数据集、11 个设置，同一预算，同一批负载。合成负载 5 个种子，真实轨迹（caida_flow）1 次。
- **评估窗口**：前 25% 的查询是所有方法共同的学习期。stacked 用这段离线建负例层，缓存类方法在这段在线预热，状态延续到后面。**所有方法只比较后 75% 的误报率。**
  - 初版没有这样处理：stacked 的已知负例取自同一条流的前 25%，评估却覆盖整条流，相当于事先知道了误报 key，小查询池的负载上它几乎零误报。已改正。
- **代价**：相对"网格比例与所有方法里该负载最好的那个"计算，分子分母各加 1 次误报做平滑。

## 参加对比的方法

| 方法 | 说明 |
|---|---|
| **误报流模型**（我们） | 实验 9 的静态版：在整条轨迹上测量后选一次比例，草图开销计入预算 |
| **在线控制器**（我们） | 实验 9 的只增不减版 |
| PLBF（0% 缓存） | 原版 Gama/PLBF 的形态。模型固定 48 树，没有复现 Gama 对模型大小的搜索 |
| TODS-CAF(BF) / (PLBF) | 经典 BF 或 PLBF，加 LRU 负例缓存。缓存定额每成员 1 bit：TODS 原文没下载到，这是按"缓存 = adaptivity 位数"的读法 |
| SkiQF 式二次准入 | 比例和我们的模型相同，只把准入改成"第二次误报才写缓存" |
| 纯 AQF / 纯 SkiQF(α=1) | 只在放得下的预算下测：Caida 1MiB、Shalla 2MiB、真实轨迹 128KiB |
| learned stacked（事后最优） | PLBF → 已知负例 BF → 成员 BF。缓存比例和负例层每 key 位数都取事后最优，对它有利 |

其余基线的情况：
- **TODS-CAF(BF)**：差 14 倍到上百万倍。在这些预算下，经典 BF 本身就不行。
- **纯 AQF / 纯 SkiQF**：在能放下的三个设置里，最坏差 2000–5500 倍。在每成员 5–8 bit 的预算下，AQF 的指纹太短，例如真实轨迹 128KiB 时 FPR 为 19%。

**种子间波动**（我们两种方法的标准差 ÷ 均值）：中位数 3.7%，90 分位 33%。波动大的都是 FPR 极小的格子，在那里几次误报的差别就会放大成很大的比例。

## 结论

1. **误报流模型在所有 11 个设置上的最坏代价都是最低的**（个别设置与控制器持平），范围 1.05–2.19 倍，中位数 1.00–1.19 倍。
2. **learned stacked 是最强的离线基线，但它怕负载变化。** 它在中位数上不差（1.06–1.97 倍），但最坏达 4.7–17 倍。它的负例层是静态的，挡不住学习期之后才出现的误报 key，所以在漂移和查询池大的负载上会失效。在真实轨迹上它排第三。
3. **SkiQF 式二次准入**（同样的比例）最坏差 1.19–9.5 倍。每个 key 多误报一次的代价在重复型负载上不划算。
4. **TODS 式定额缓存**（每成员 1 bit）比不加缓存好得多，但比按负载定比例差（最坏 1.65–4.7 倍）。这也说明了贡献 2 的价值：缓存该给多少需要计算，不能拍一个定额。
5. **纯 AQF 在 learned filter 的有利区间里不可用。** 它要么放不下，要么指纹太短。这再次印证了"放行区只能靠缓存"。
6. **在线控制器的中位数不错（1.03–1.95 倍），但最坏会到 5–12 倍。** 原因是加多了：例如 COD 256KiB 的全池均匀负载，控制器把缓存加到 19.8%，而最优是 10%。多出来的内存靠把分段改成直接放行腾出，又带来了新的误报，而只增不减意味着收不回来。论文里控制器的代价上界要如实写成"可能过冲"。可以改进的方向有三个：候选步长更细、每次只走一半、要求预测收益超过一个阈值才增加；这次都没有改。

## 局限

- TODS-CAF 的缓存定额是我们的读法（原文 PDF 下载超时，无法核对）。
- stacked 只实现了"PLBF + 两层 BF"的 learned 版本，没有实现 Deeds 等人原版的多层代价优化。
- Gama 只复现了 PLBF 形态，没有做模型大小搜索。
- Caida 那部分实验跑的过程中 Mac 多次进入休眠，所以墙钟时间不可信，但不影响结果的正确性（模拟是确定性的）。
