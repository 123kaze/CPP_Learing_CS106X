## 3. adv* 负载的构造：属于重复型（情形 ①），不能叫对抗鲁棒性

代码见 `common.simulate`。每条查询以概率 p（2% 或 10%）交给对抗者，其余是测试池上的均匀查询。对抗者：

- 手里有已知误报 key 时，以 90% 的概率从中均匀抽一个**重放**，否则从测试池均匀抽一个新 key **探测**；
- 探测得到误报，就把这个 key 加进已知集合；重放时如果不再误报（被 AQF 修掉了），就把它移出；
- 测试池只有 99.96 万个 key，对抗者能找到的误报 key 就是这个池子里的那批（256KiB 下约 1.6–6 千个），之后一直重放。

所以它是“探测＋重放”：对静态结构，它等价于把查询集中到一小批固定的误报 key 上，属于重复型负载。论文里应叫“探测重放负载”或“自适应重复负载”，不能拿它说对抗鲁棒性。实验 2 另加了“全新对抗”负载：按模型分数从高到低取测试池里的 key，每个只查一次。
