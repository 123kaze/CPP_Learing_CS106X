2026-11-22。此处记录候选格式、可访问性与边界。第35轮本机TCP对照已完成并发布；[第36轮](../windows_research/round36_http_qualification/README.md)已经完成ClarkNet／Saskatchewan资格审计，三份官方日志完整下载并通过Range/CRC/SHA校验。**ClarkNet通过预设资格门槛，Saskatchewan因404保留率89.00%未达90%而未通过**。[第37轮](../windows_research/round37_clarknet_controls/README.md)已完成ClarkNet的45条主比较＋27条固定配置消融：完整RA相对BF+Cache仅3/9胜，固定配置miss相对traffic为8/9胜，不等同于模型整体稳定占优。不能把“请求很多”直接当成“成员目录大、模型有价值”。

## 筛查要求

优先寻找可复现、保留请求顺序和可用key特征的真实轨迹。若研究“缺失资源查询”，需要真实HTTP不存在响应或独立可信成员目录；不能把cache miss、零字节、数据库更新标记当作nonmember标签。

正式采用前还要检查：唯一成员/key规模、标签冲突、训练/验证与尾段隔离、真实负查询重复度、score region差异。不得看到尾段RA胜负之后再挑数据/预算；没有正结果就如实保留。

## 特别注意

- Squid第四列类似`TCP_MISS/200`：前半是cache结果，后半才是HTTP状态。`TCP_MISS`不能用来标记后端不存在。
- UCB请求URL已被匿名化，方法/扩展名等少量字段仍存在，但其可学习性和真实nonmember标签都未确立；不能为了大请求数回到弱模型问题。
- ClarkNet资料的首个下载链接文字日期与文件名/measurement段有差异，应按实际日志内容核实，类似NASA七月分发文件实际止于7月28日的审计。
- UCB有版权声明保留、引用和向贡献者提供论文副本等使用条件；不会擅自用用户邮箱联系作者或发布数据。
- 任何下载都应放入新的独立空目录；解析代码放在别处、用隔离Python运行；客户端IP/用户标识不用于模型，不发布原始日志。
- 当前没有选出一个已验证、明显更大且满足全部条件的新真实工作负载。该证据缺口仍未打勾。

## 新增元数据核验：Online Shopping Store – Web Server Logs

- Harvard Dataverse DOI `10.7910/DVN/3QBYB5`，首次发布2019-01-26，当前发布版本1.1（2021-05-20）。元数据描述为电商站Nginx access log，描述日期2018-12-10，不等于已核验日志实际覆盖日期。
- 官方API显示`Access.log.zip`为274021898字节，文件ID3347743，**restricted=true**；访问条款提及敏感数据。虽然元数据标注CC0，不能据此忽略实际访问限制。本次只读取公开元数据，未尝试下载受限文件、获取凭据或通过镜像绕过限制。
- 公开的browse/product/static及Normalize/WaitTimes/Aggregated派生文件存在，但尚未核验是否保留精确URL、HTTP状态和自然顺序。不能以名字推断包含真实404，也不能把聚合请求量当失败查询轨迹。
- Kaggle搜索摘要提及Zanbil及3.3GB日志，但本次网页正文只返回标题；不把搜索摘要等同于字段与授权核验。暂不加入第36轮，不用它替换已冻结候选。
