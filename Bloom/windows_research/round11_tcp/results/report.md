# 第十一轮：协议一致（只用 TCP）的真实轨迹

设计见 `plan/design-freeze.md`（写于看到结果之前）：只保留 TCP 包；前一半时间里出现过的流是成员，之后才出现的流是负例；查询是后一半的 TCP 包。key 不含协议，模型只用 src、dst。每条轨迹 1 条真实查询流，前 25% 为学习期，只统计后 75%。
