## 三、探测重放（稳健性，单列）

70 个案例：RA6-fp64 / RA6 1.090 / 162.50 / 43%；RA6-fp64 / Gama 0.045 / 1.00 / 96%（中位数 / 最坏 / ≤1 的比例）。

## 四、假阴性和代价

- 全部 1146 个案例的最终缓存状态上，用全部成员逐个查询，被缓存误判为负例的成员数合计：**0**。
- 理论上界：每次成员查询的假阴性概率 ≤ 已占用槽位数 × 2^-64，所有案例中最大为 2.40e-15。
- 982/1146 个案例用了缓存。
- 与第六轮选出的树数相同、且是否用缓存相同的案例：80%。
- 不再需要成员哈希索引：省掉每个成员 8 字节的预算外内存，缓存插入也不再需要查索引。
