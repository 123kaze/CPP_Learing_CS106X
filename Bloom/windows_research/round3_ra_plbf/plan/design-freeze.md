# 方法 C（RA-PLBF）：实现说明与冻结记录（2026-10-29）

本轮在 Mac 上执行，代码在 `round3_ra_plbf/src/`。直接复用第二轮的引擎（`round2_backlog/src/engine.py`）：同样的物理记账（真实打包的 BF、模型数组、导航数组、数组头、按 2 的幂分桶的 4 路 CLOCK 缓存的实际分配字节），同样的流、学习期和冷启动尾段。部署状态不计草图。

## 与"C 方法设计"表的对应和改动

| 设计表 | 实现 |
|---|---|
| 学习期按分段统计 Q_i、D_i、频次分布 | 学习期内逐 key 计数（主方法），换算到每段（每个候选树数各算一次）。消融 RA-Zipf 只用每段的 (Q_i, D_i, 前 256 个 key 的查询占比) 拟合 Zipf |
| Che 近似，M_i(T)、O_i(T) | 每个 key 的尾段速率 λ 用学习期计数估计，计数 ≤5 时用 Good–Turing 修正；尾段冷启动：第一次必然不命中，之后间隔超过 T 才不命中。学习期没出现过的 key 的尾段查询量用 Good–Turing（单次出现的 key 数 / 学习期长度）估计，按"一半照学习期单次 key 所在的分段、一半照验证集负例"分到各段，视为只查一次 |
| 固定 T 时 ε_i 闭式解，对 μ 二分 | 相同：ε_i = min(1, μ·n_i/((ln2)²·M_i(T)))，μ 二分到 BF 位数用满 |
| 对 T 一维搜索 | 物理缓存只有离散的几档（桶数为 2 的幂），所以逐档枚举实际分配字节和槽数 S。每档取"ε(T) 仍装得进 S 槽的最大 T"（占用一致），不另设 b 的连续松弛 |
| （设计表未列） | **组相联修正**：4 路分桶时小缓存会互相挤出。开发集第一次运行时，64 槽缓存的预测为 45、实测为 341。按泊松桶负载修正：分到 X 个 key 的桶等价于全体用 S·d/X 槽（d 为每桶平均 key 数）。没有拟合常数；修正后再解 3 轮 ε |
| 外层搜索 Gama 树数 | 相同，候选树数与 Gama 一致 |
| 部署：按 ε_i 建 BF | 最终权重 M_i 交给原 PLBF 离散分配器（`common.allocate`：整数哈希数，PASS/EMPTY），因此不存在"ε_i 取整"的偏差 |
| 缓存每槽成本用实测值 | 直接用每档布局的实际分配字节 |

**护栏版 RA-PLBF+G**（"任何设置下不比 Gama 差"）：开发集里全新对抗负载的尾段 key 和学习期的不在同一批分段，RA-PLBF 因此比 Gama 差 11.7 倍。加了时序自检：在学习期前 3/4 上拟合 RA-PLBF，与 Gama 一起在后 1/4 上精确回放；RA 不差才部署（用全部学习期拟合的）RA-PLBF，否则部署 Gama。只比较这两个配置，不是网格。两个版本都报告。

## 固定的常数（全部在评估前确定，没有在评估集上调过）

GT_MAX=5，NEW_MIX=0.5，GUARD_SPLIT=0.75，T 网格 160 点（0 和 1 到 1000·H 的对数网格），组相联修正 3 轮，前缀 40 位，4 路，CLOCK。

## 开发集（看过结果的设置）

- COD 256KiB，1M 查询，种子 0，负载：uniform-1万、zipf1.1-全部、每key一次、全新对抗、向难负例漂移。
- caida_flow 16/24/32KiB（完整轨迹）。

所有其他设置（COD 1024；Caida、Shalla、URL 的全部预算；MAWI 2021、MAWI 2022），以及 COD 256 在完整规模（10M 查询、5 种子、全部负载）下的结果，都在冻结后第一次运行。注意：这些数据集都已经被第二轮用于其他方法，它们只对方法 C 的设计是"未接触"的。

## 已知风险（冻结前已观察到）

- 向难负例漂移：难负例比例在尾段持续上升，学习期速率低估尾段，RA-PLBF 选择不加缓存（开发集为网格的 2.8 倍）。护栏只防"比 Gama 差"，不修这一点。
- 学习期逐 key 计数的状态在学习结束后释放，不计入部署预算，单独报告（`learning_state_bytes`）。

## 对比与判据

同一流上对比：Gama、误报流模型（StreamModel）、学习期网格回放（LearnGrid，全局缓存比例）、固定 48 树＋缓存网格（Fixed48Grid）、RA-PLBF、RA-PLBF+G，以及消融 RA-Zipf（Zipf 拟合代替经验频次）、RA-NoRepeat（分配时不打重复折扣，退化为学习期 PLBF＋缓存）、RA-GlobalCache（分配沿用验证集权重，只选全局缓存大小）。

决策关口 C5 的判据（来自总任务表）：多数设置下不比网格回放差，且任何设置下不比 Gama 差。
