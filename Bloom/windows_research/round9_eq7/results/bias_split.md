# RA6 预测偏高从哪里来：按学习期见过 / 没见过的 key 拆分

对每个 E3 案例里 RA6 选中的结构（与 `report.md` 同一批案例），把预测和评估段实测的缺失数都拆成两部分：学习期见过的 key（按 Che 和 Good-Turing 速率预测，式 7）和学习期没见过的 key（G_i = H·N1/L·h_i 次查询乘分段 FPR，全部当作缓存挡不住，式 5）。未见 key 再给出无缓存时的实测误报（查询次数）和不同 key 数（有缓存时的下界）。相对误差 =（预测 − 实测）/ 实测，逐案例计算后取中位；它恰好等于"未见 key 部分"与"见过 key 部分"之和（两部分都除以同一个总实测），但三列的中位数不必相加相等。后面几列是组内求和后的比。
