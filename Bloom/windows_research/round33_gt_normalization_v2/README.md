## 方案

不改变原L、N1与counts的含义。设已见率总和R、未见质量u=N1/L：

- **GT19**：冻结控制，完全走原预测函数。

## 给稿件/方法的建议（仅MD）

GT19并非规范化概率分布，这个数学事实仍需明确。保留原方法不等于可以省略总质量问题；应该将其准确描述为GT启发的近似有效到达率/评分量，并披露可能过质量或欠质量。改称“rate”本身不能消除概率解释上的限制。

另一方面，“除以总质量”并非不改变算法的文字修复。本实验实际展示了它会改变选择与FP，而没有稳定收益。若未来需要概率一致的生成模型，应另行设计并用学习/验证期选择，不能根据这里的尾段输赢选赢家。

论文没有继续改动；此轮是事后实验，不是MAWI24冻结前的新保证。
