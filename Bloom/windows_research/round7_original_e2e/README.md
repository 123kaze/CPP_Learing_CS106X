# 原版 Gama vs RA6：从训练到实际查询（2026-11-01）

这是新的系统实验目录，不是 RA7 方法。只导入冻结的 RA6/DP/CLOCK 代码，不修改旧实验。

## 预定范围

- E4/E7 的 8 个代表设置：cod 1024、caida 256、shalla 1024、url 128、caida_flow/mawi2020_flow/mawi2021_flow/mawi2022_flow 各 24KiB。
- 合成流 `zipf1.0-全部`，seed 0，总长 1000 万；真实流保持原顺序。前 25% 用于 RA6 选择，后 75% 从空缓存开始。
- 每个方法每个设置 **3 次独立进程、从头训练和构建**；串行、单线程，轮换先后顺序。不是 3 个随机数据种子。
- 附加 URL 128 和 caida_flow 16KiB 冒烟测试；16KiB 原版若失败如实记录，不记作胜出。

## 两个被测方法

- **Gama(original)**：直接执行 `original_baselines/gama/run_gama_plbf_ada.py` 中训练与搜索原文（官方 `27a454a` 的输入/输出适配副本），使用官方 `FastPLBF_M` 和 `bloom_filter`。仅替换搜索后的评估/输出部分来计时，不改模型参数、贝叶斯搜索、分段 N=50、k=5、pickle 预算规则。
- **RA6**：重新训练原参数的 200 树模型，所有候选分数重新计算，只给成员、验证负例、学习期不同 key 打分；学习查询下标压缩到这些 key，直接调用冻结的 `ra6.select6`。部署调用 E7 的真实树遍历/打包 BF/CLOCK 查询路径。全尾段 FP、树数和缓存字节必须复现主表。
- 两者看到相同特征与划分。原版从其 CSV 读入，RA6 从原始特征缓存读入；CSV/NPZ 读取和共有工作负载生成不算算法构建成本，另报数据准备时间。两者均不复用训练好的模型、候选分数、选中结构或 FP 标记。

## 实测项

1. 从内存训练数据到可部署过滤器：训练、候选打分/选择、构建（原版训练与搜索交织，合报）；RA6 的模型数组转换和最终可执行 BF 重建计入。
2. 整个负查询尾段：实际查询并计时，每 1000 条一次 API 调用；报告 FP、FPR、秒、ns/query。每次出现都真实推理/查过滤器，绝不使用预存 FP 标记计时。
3. 同一个负查询尾段前 20 万条，按固定种子混入 10% 成员：batch=1000；另取前 2 万条 batch=1。分别报告耗时、FP/负查询数、FN。缓存每种测量都重置为空。
4. 单独对全部成员实际查询，检查零假阴性；RA6 还检查原生打分等于新训 LightGBM，以及主表回归。校验耗时不算服务耗时。
5. 报告 `train_to_ready_s + full_tail_query_s` 作为训练到完成全尾段的总计算时间；数据准备、JIT 预热、校验、进程墙钟另外记录，不偷藏进某个方法的构建时间。

**这次不包含数据库、网络或磁盘后端点查延迟**；“端到端查询”指输入特征 → 模型 → BF/缓存 → 过滤器判定。RA6 的验证反馈由成员真值提供，安全前缀二分查找实际执行且计时。

## 公平性与解释边界

- 这是原版实现与 RA6 实现的系统对比，不是同语言内核的算法消融。原版 Python/LightGBM/bloom_filter 对 RA6 Numba 紧凑数组，速度差包含实现差异；batch=1 与 batch=1000 不能混报。
- 原版内存记账不修改，RA6 严格物理记账。报告原版 pickle 模型大小、BF 目标位数和实际 BF 数组容量，不能只根据预算参数声称两者实际内存相同。
- RA6 安全前缀所需成员索引（8 B/member）在过滤器预算外，计入构建时间并单列字节；原版不需要它。
- JIT 先用无关小输入预热、单列时间。各次训练和选型仍重新运行。
- 没有自动重试数值失败、内存终止或原版不可构建；异常写入结果，不能将失败行变成 0 FP。

## 命令

从本目录运行：

```bash
../../.condaenv/bin/python -u src/run.py --datasets caida_flow --reps 1 --suffix smoke
../../.condaenv/bin/python -u src/run.py --reps 3
../../.condaenv/bin/python -u src/report.py
```

长任务由 harness 后台运行 `caffeinate -s -i ...`。输出在 `results/`，输入/轨迹固定件在 `inputs/`（git 忽略），每个方法日志独立保存。
