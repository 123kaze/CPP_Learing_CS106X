**User**

为什么我的mysql必须要sudo才能登陆root？sql密码是123456

---


**OpenAI Codex**

因为 Ubuntu/Debian 上 MySQL 的 `root` 用户默认常常不是用密码登录，而是用 `auth_socket` / `unix_socket` 认证。

意思是：

```bash
sudo mysql
```

能进，是因为系统看到“你是 Linux 的 root 权限”，所以允许你作为 MySQL 的 `root` 进去。

但：

```bash
mysql -u root -p
```

会失败，是因为 MySQL 的 `root@localhost` 可能根本不看你输入的 `123456`，它只认系统 socket 身份。所以你感觉“必须 sudo 才能登录 root”。

你可以进 MySQL 后检查一下：

```sql
SELECT user, host, plugin FROM mysql.user WHERE user='root';
```

如果看到类似：

```text
root | localhost | auth_socket
```

那就是这个原因。

如果你想让 root 用密码 `123456` 登录，可以执行：

```bash
sudo mysql
```

然后在 MySQL 里执行：

```sql
ALTER USER 'root'@'localhost' IDENTIFIED WITH mysql_native_password BY '123456';
FLUSH PRIVILEGES;
```

之后就可以：

```bash
mysql -u root -p
```

然后输入 `123456`。

不过更推荐的做法是不要改 MySQL 的 root，而是新建一个日常用户，比如：

```sql
CREATE USER 'kaze'@'localhost' IDENTIFIED BY '123456';
GRANT ALL PRIVILEGES ON *.* TO 'kaze'@'localhost' WITH GRANT OPTION;
FLUSH PRIVILEGES;
```

然后平时用：

```bash
mysql -u kaze -p
```

这样更干净，也更符合 Ubuntu 的默认安全设计。
