## 3. 核心库 & 常用 API

### `datetime` —— 日期和时间对象

```python
from datetime import datetime, date, time, timedelta

# 获取当前时间
now = datetime.now()           # 本地当前时间
today = date.today()           # 今天日期

# 创建时间对象
dt = datetime(2026, 7, 20, 14, 30, 0)
d = date(2026, 7, 20)

# 字符串 ↔ 时间对象
dt = datetime.strptime("2026-07-20", "%Y-%m-%d")     # 字符串 → datetime
s = dt.strftime("%Y-%m-%d %H:%M:%S")                  # datetime → 字符串
s = dt.isoformat()                                     # ISO 格式: "2026-07-20T14:30:00"

# 时间计算
tomorrow = today + timedelta(days=1)
yesterday = today - timedelta(days=1)
one_hour_later = now + timedelta(hours=1)
diff = datetime(2026, 7, 20) - datetime(2026, 7, 9)  # timedelta
print(diff.days)  # 11

# 比较
if dt > now:
    print("未来")
elif dt < now:
    print("过去")
else:
    print("现在")
```

### 常用格式化代码

| 代码 | 含义 | 示例 |
|------|------|------|
| `%Y` | 四位年份 | 2026 |
| `%m` | 两位月份 | 07 |
| `%d` | 两位日期 | 09 |
| `%H` | 24小时制 | 14 |
| `%M` | 分钟 | 30 |
| `%S` | 秒 | 00 |
| `%A` | 星期（全名） | Thursday |
| `%a` | 星期（缩写） | Thu |
| `%B` | 月份（全名） | July |
| `%b` | 月份（缩写） | Jul |

### `time` —— 时间戳和暂停

```python
import time

time.time()           # Unix 时间戳（秒）
time.sleep(1.5)       # 暂停 1.5 秒
```

### `calendar` —— 日历显示

```python
import calendar

calendar.month(2026, 7)     # 打印 2026 年 7 月日历
calendar.isleap(2026)       # 是否为闰年
```

## 4. 最小可运行例子

```python
from datetime import datetime, date, timedelta

# 判断一个日期是否过期
due = date(2026, 7, 10)
today = date.today()

if today > due:
    print(f"已过期 {(today - due).days} 天")
elif today == due:
    print("今天截止!")
else:
    print(f"还有 {(due - today).days} 天")
```

## 5. 实验任务

### 任务：给 Todo 加上截止日期

基于实验 04 的 `todo.py`，添加时间管理功能。

```bash
# 添加带截止日期的任务
python todo.py add "submit homework" --due 2026-07-20
python todo.py add "buy milk" --due tomorrow
python todo.py add "read book" --due "next Monday"

# 查看今天的任务
python todo.py today

# 查看过期的任务
python todo.py overdue

# 查看本周任务
python todo.py week

# 列出任务时显示截止日期和剩余天数
python todo.py list
# 输出:
# ⬜ #1 [high  ] 提交作业    截止: 2026-07-20 (还有 11 天)
# ⬜ #2 [medium] 买牛奶      截止: 2026-07-10 ⚠️ 已过期 1 天
```

要求：
1. `--due` 接受多种格式：`YYYY-MM-DD`、`tomorrow`、`today`、`next Monday`
2. `list` 显示截止日期和剩余/过期天数
3. `today` 显示今天到期的任务
4. `overdue` 显示所有过期未完成的任务
5. 过期任务有视觉标记（⚠️）

### 进阶挑战

- 支持 `--due "3d"` 表示 3 天后
- 支持定时提醒（用 `time.sleep()` 等待到指定时间后打印提醒）

## 6. 常见错误

| 错误 | 原因 |
|------|------|
| `datetime` 和 `date` 不能直接比较 | 类型不同，用 `.date()` 转换 |
| 时区混淆 | `datetime.now()` 是本地时间，没有时区信息 |
| `strptime` 格式不匹配 | 格式字符串必须和输入完全对应 |
| `timedelta` 没有 `.years` | 只有 days/seconds/microseconds |
