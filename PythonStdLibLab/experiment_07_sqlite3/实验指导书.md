# 实验 07：数据库

## 1. 实验目标

学会用 `sqlite3` 把数据从内存/JSON 文件升级到真正的数据库——建表、增删改查、参数化查询。

**核心意识**：文件存储适合简单场景；当数据量变大、需要查询和关系时，数据库是更好的选择。SQLite 是零配置的嵌入式数据库，Python 自带支持。

## 3. 核心 API

### 连接和游标

```python
import sqlite3

# 连接（文件不存在则自动创建）
conn = sqlite3.connect("todo.db")

# 游标：执行 SQL 和获取结果
cur = conn.cursor()

# 执行完记得提交
conn.commit()

# 关闭
conn.close()
```

### 建表

```python
cur.execute("""
    CREATE TABLE IF NOT EXISTS tasks (
        id INTEGER PRIMARY KEY AUTOINCREMENT,
        title TEXT NOT NULL,
        done INTEGER DEFAULT 0,
        priority TEXT DEFAULT 'medium',
        due_date TEXT,
        created_at TEXT DEFAULT (datetime('now'))
    )
""")
conn.commit()
```

### 增删改查 (CRUD)

```python
# CREATE —— 用 ? 占位符防止 SQL 注入
cur.execute(
    "INSERT INTO tasks (title, priority) VALUES (?, ?)",
    ("learn sqlite3", "high")
)
conn.commit()
new_id = cur.lastrowid  # 刚插入的行 ID

# READ
cur.execute("SELECT * FROM tasks WHERE done = 0")
rows = cur.fetchall()          # 所有结果：[(id, title, ...), ...]
row = cur.fetchone()           # 一行
for row in cur.execute("SELECT * FROM tasks"):
    print(row)

# UPDATE
cur.execute("UPDATE tasks SET done = 1 WHERE id = ?", (task_id,))
conn.commit()

# DELETE
cur.execute("DELETE FROM tasks WHERE id = ?", (task_id,))
conn.commit()
```

### 使用 Row 工厂（让结果像字典）

```python
conn.row_factory = sqlite3.Row
cur = conn.cursor()
cur.execute("SELECT * FROM tasks")
for row in cur:
    print(row["title"], row["priority"])  # 用列名访问！
```

### 用 `with` 自动提交/回滚

```python
with conn:
    conn.execute("INSERT INTO tasks (title) VALUES (?)", ("task 1",))
# with 块退出时自动 commit（或异常时 rollback）
```

## 4. 文件存储 vs 数据库

| | JSON 文件 | SQLite |
|------|-----------|--------|
| 查询 | 读全部 → 手动过滤 | `SELECT ... WHERE` |
| 排序 | 手动排序 | `ORDER BY` |
| 搜索 | 手动遍历 | `LIKE` / 全文搜索 |
| 并发 | 需要锁 | 内置 WAL 模式 |
| 数据量 | 内存限制 | 磁盘存储 |
| 依赖 | 无 | 无（标准库自带） |

## 5. 最小可运行例子

```python
import sqlite3

# 连接数据库
conn = sqlite3.connect("demo.db")
conn.row_factory = sqlite3.Row

# 建表
conn.execute("CREATE TABLE IF NOT EXISTS users (id INTEGER PRIMARY KEY, name TEXT)")

# 插入
conn.execute("INSERT INTO users (name) VALUES (?)", ("Alice",))
conn.commit()

# 读取
for row in conn.execute("SELECT * FROM users"):
    print(f"#{row['id']}: {row['name']}")

conn.close()
```

## 7. 常见错误

| 错误 | 原因 |
|------|------|
| `sqlite3.OperationalError: no such table` | 忘了建表 |
| `sqlite3.OperationalError: near "X": syntax error` | SQL 语法错误 |
| 数据没保存 | 忘了 `conn.commit()` |
| SQL 注入 | 用字符串拼接而不是 `?` 占位符 |
| 中文乱码 | 数据库本身支持 UTF-8，检查读写时的编码 |

## 8. SQL 注入演示（**重要！**）

```python
# ❌ 危险：字符串拼接
task_id = "1; DROP TABLE tasks; --"
cur.execute(f"DELETE FROM tasks WHERE id = {task_id}")   # 整张表被删！

# ✅ 安全：参数化查询
cur.execute("DELETE FROM tasks WHERE id = ?", (task_id,))  # 只会删除 id='1; DROP...'（找不到，不删）
```

> 规则：**永远用 `?` 占位符，永远不要拼接用户输入到 SQL 语句中！**
