# 实验 04：日志

## 1. 实验目标

学会用 `logging` 模块替代 `print()`，理解日志级别、格式化、输出目标（控制台 / 文件）。

**核心意识**：真实程序不能只靠 `print()` 调试。日志可以：
- 分级（DEBUG < INFO < WARNING < ERROR < CRITICAL）
- 持久化到文件
- 在生产环境灵活控制输出量
- 记录时间、模块名、行号等上下文

## 3. 核心 API

### 快速上手

```python
import logging

# 基础配置（只配置一次，放在程序入口）
logging.basicConfig(
    level=logging.DEBUG,                      # 最低输出级别
    format="%(asctime)s [%(levelname)s] %(message)s",
    datefmt="%Y-%m-%d %H:%M:%S",
    handlers=[
        logging.FileHandler("app.log"),       # 输出到文件
        logging.StreamHandler(),               # 输出到控制台
    ],
)

# 获取 logger（每个模块一个）
logger = logging.getLogger(__name__)

# 使用
logger.debug("变量 x = %d", x)       # 调试信息（默认不输出）
logger.info("服务器启动在端口 %d", port)   # 一般信息
logger.warning("磁盘空间低于 10%%")       # 警告
logger.error("连接数据库失败: %s", e)      # 错误
logger.critical("系统崩溃，即将退出")      # 致命错误
```

### 日志级别

```
DEBUG       → 10   开发调试时用
INFO        → 20   正常运行时的重要事件
WARNING     → 30   可能出问题但不影响运行
ERROR       → 40   出了错误但程序还能继续
CRITICAL    → 50   致命错误，程序可能无法继续
```

### 格式变量

```python
"%(asctime)s"       # 时间
"%(name)s"          # logger 名称（通常是模块名）
"%(levelname)s"     # 日志级别
"%(filename)s"      # 文件名
"%(lineno)d"        # 行号
"%(funcName)s"      # 函数名
"%(message)s"       # 日志消息
```

### 进阶：不同模块不同 logger

```python
# database.py
import logging
logger = logging.getLogger("todo.database")
logger.info("数据库已连接")

# cli.py
import logging
logger = logging.getLogger("todo.cli")
logger.info("用户执行了 add 命令")
```

## 4. 最小可运行例子

```python
import logging

logging.basicConfig(
    level=logging.INFO,
    format="%(asctime)s [%(levelname)s] %(message)s",
)

logger = logging.getLogger(__name__)

def divide(a, b):
    logger.info("divide(%d, %d) 被调用", a, b)
    try:
        result = a / b
        logger.debug("结果 = %f", result)
        return result
    except ZeroDivisionError:
        logger.error("除零错误!")
        raise

print(divide(10, 2))
print(divide(10, 0))
```

要求：

## 6. 常见错误

| 错误 | 原因 |
|------|------|
| 日志不输出 | `level` 设得太高，或 logger 的级别比 handler 更高 |
| 日志输出两次 | 同时 add 了 handler 又调了 `basicConfig` |
| 日志文件不写入 | 程序没正常退出（缺少 `flush`），或在错误目录 |
| `basicConfig` 不生效 | 它只在第一次调用时生效，之后的调用被忽略 |

---

## 7. `logging` vs `print`

| | `print()` | `logging` |
|------|-----------|-----------|
| 输出目标 | 只有 stdout | 文件、控制台、网络、邮件... |
| 分级控制 | 无 | 5 个级别，可按需过滤 |
| 时间戳 | 要手写 | 内置 |
| 生产环境 | 要逐个删除 | 一行改级别即可关闭 DEBUG |
| 性能 | 快 | 稍慢（可忽略） |
| 适用场景 | 临时调试 | 正式项目 |
