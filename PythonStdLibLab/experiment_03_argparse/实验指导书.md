## 3. 核心 API

### `argparse` 三步走

```python
import argparse

# 第 1 步：创建解析器
parser = argparse.ArgumentParser(
    prog="myapp",
    description="我的命令行工具",
    epilog="更多信息请看文档"
)

# 第 2 步：添加参数
parser.add_argument("input", help="输入文件路径")              # 位置参数（必填）
parser.add_argument("-o", "--output", default="out.txt")       # 可选参数
parser.add_argument("-v", "--verbose", action="store_true")    # 开关（True/False）
parser.add_argument("-n", "--count", type=int, default=1)      # 带类型的参数
parser.add_argument("--items", nargs="+")                      # 接受多个值
parser.add_argument("--mode", choices=["fast", "slow"])        # 限定选项

# 第 3 步：解析
args = parser.parse_args()
print(args.input, args.output, args.verbose)
```

### 子命令（subparsers）

```python
parser = argparse.ArgumentParser()
subparsers = parser.add_subparsers(dest="command")

# add 子命令
parser_add = subparsers.add_parser("add", help="添加任务")
parser_add.add_argument("title", help="任务标题")

# list 子命令
parser_list = subparsers.add_parser("list", help="列出任务")
parser_list.add_argument("--all", action="store_true")

# done 子命令
parser_done = subparsers.add_parser("done", help="标记完成")
parser_done.add_argument("id", type=int, help="任务 ID")

args = parser.parse_args()
if args.command == "add":
    print(f"添加: {args.title}")
elif args.command == "list":
    print("列出所有任务")
elif args.command == "done":
    print(f"完成任务 #{args.id}")
```

## 4. 最小可运行例子

```python
import argparse

parser = argparse.ArgumentParser(description="问候程序")
parser.add_argument("name", help="你的名字")
parser.add_argument("--greeting", default="Hello", help="问候语")
args = parser.parse_args()

print(f"{args.greeting}, {args.name}!")
```

运行：
```bash
python greet.py Alice --greeting "Good morning"
# 输出: Good morning, Alice!
```

## 5. 实验任务

### 任务：命令行 Todo（内存版）

写一个 `todo.py`，数据先存在内存列表中（下次启动丢失也没关系）。

```bash
# 添加任务
python todo.py add "learn pathlib"

# 列出所有任务
python todo.py list

# 标记任务为已完成
python todo.py done 1

# 删除任务
python todo.py remove 1

# 清空所有任务
python todo.py clear
```

要求：
1. 使用子命令（`add` / `list` / `done` / `remove` / `clear`）
2. 每个任务有 id（自动递增）和标题
3. `list` 显示任务状态（✅ / ⬜）
4. 友好的帮助信息（`--help` 能看懂每个命令的用法）
5. 参数校验（比如 `done 999` 时任务不存在，给出合理提示）

### 进阶挑战

- 添加 `--priority high/medium/low` 参数
- `list --done` 只看已完成的 / `list --todo` 只看未完成的
- 支持 `todo edit 1 "new title"` 编辑任务

## 6. 常见错误

| 错误 | 原因 |
|------|------|
| `error: unrecognized arguments` | 拼写错误或传了没定义的参数 |
| `error: argument ... expected one argument` | 需要传值但没传 |
| `error: invalid choice` | 传了不在 `choices` 里的值 |
| 子命令不生效 | 忘了 `dest="command"` 或没正确判断 `args.command` |

## 7. `argparse` vs `sys.argv`

```python
# 用 sys.argv（手动解析，不推荐）
import sys
name = sys.argv[1]  # 没有类型检查、没有帮助信息、容易出错

# 用 argparse（推荐）
import argparse
parser = argparse.ArgumentParser()
parser.add_argument("name")
args = parser.parse_args()
# 自动生成 --help、自动类型检查、自动错误提示
```
