## 3. 核心库 & 常用 API

### `pathlib` —— 面向对象的路径操作（推荐优先学）

```python
from pathlib import Path

# 创建路径对象
p = Path("/home/user/project")

# 常用属性和方法
p.exists()          # 路径是否存在
p.is_file()         # 是否是文件
p.is_dir()          # 是否是目录
p.suffix            # 文件后缀名，如 ".py"
p.name              # 文件名（含后缀）
p.stem              # 文件名（不含后缀）
p.parent            # 父目录
p.mkdir(parents=True, exist_ok=True)  # 创建目录
p.iterdir()         # 遍历目录（不递归）
p.glob("*.py")      # 按模式匹配（不递归）
p.rglob("*.py")     # 递归按模式匹配
p.read_text()       # 读取文本内容
p.write_text("...") # 写入文本内容
```

### `shutil` —— 高级文件操作

```python
import shutil

shutil.copy(src, dst)        # 复制文件
shutil.copy2(src, dst)       # 复制文件（保留元数据）
shutil.copytree(src, dst)    # 递归复制目录
shutil.move(src, dst)        # 移动文件或目录
shutil.rmtree(path)          # 递归删除目录
```

### `os` —— 底层操作系统接口

```python
import os

os.listdir(path)             # 列出目录内容（返回文件名列表）
os.path.join(a, b)           # 拼接路径
os.path.getsize(path)        # 获取文件大小（字节）
os.stat(path)                # 获取文件详细信息
```

### `glob` —— Unix 风格路径匹配

```python
import glob

glob.glob("*.py")            # 当前目录所有 .py 文件
glob.glob("**/*.py", recursive=True)  # 递归查找
```

## 4. 最小可运行例子

```python
from pathlib import Path

# 统计当前目录下各类文件的数量
counts = {}
for f in Path(".").iterdir():
    if f.is_file():
        ext = f.suffix or "(无后缀)"
        counts[ext] = counts.get(ext, 0) + 1

for ext, count in sorted(counts.items()):
    print(f"{ext:10s}: {count} 个")
```

## 5. 实验任务

### 任务：文件分类器

写一个 `file_classifier.py`，功能如下：

```bash
# 基本用法：扫描目录，输出统计信息
python file_classifier.py /path/to/folder

# 按类型分类复制到目标目录
python file_classifier.py /path/to/folder --copy-to ./sorted

# 只统计特定后缀
python file_classifier.py /path/to/folder --ext .py .cpp .txt
```

要求：

1. 递归遍历目录下所有文件（用 `rglob`）
2. 统计每种后缀的文件数量
3. 支持 `--copy-to` 参数：按后缀创建子目录，把文件复制过去
4. 输出格式清晰

**目录结构效果**：
```
sorted/
├── py/
│   ├── main.py
│   └── utils.py
├── txt/
│   └── readme.txt
└── (no_extension)/
    └── Makefile
```

### 进阶挑战

- 统计每种类型文件的总大小
- 找出最大的 5 个文件
- 用 `--move` 代替 `--copy-to`（移动文件而非复制）

## 6. 常见错误

| 错误 | 原因 |
|------|------|
| `FileNotFoundError` | 路径不存在 |
| `PermissionError` | 没有读写权限 |
| `IsADirectoryError` | 把目录当文件操作 |
| `NotADirectoryError` | 把文件当目录操作 |
| `pathlib` 和 `os.path` 混用 | 路径对象和字符串不是同一类型，用 `str(p)` 转换 |
