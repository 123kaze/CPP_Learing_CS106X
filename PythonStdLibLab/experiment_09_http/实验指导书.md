## 3. 核心 API

### `http.server` —— 简易 HTTP 服务器

```python
from http.server import HTTPServer, BaseHTTPRequestHandler
import json

class MyHandler(BaseHTTPRequestHandler):
    def do_GET(self):
        # 解析路径
        if self.path == "/":
            self.send_response(200)
            self.send_header("Content-Type", "text/html; charset=utf-8")
            self.end_headers()
            self.wfile.write(b"<h1>Hello, World!</h1>")

        elif self.path == "/api/tasks":
            self.send_response(200)
            self.send_header("Content-Type", "application/json")
            self.end_headers()
            data = json.dumps([{"id": 1, "title": "learn http"}])
            self.wfile.write(data.encode("utf-8"))

        else:
            self.send_response(404)
            self.end_headers()
            self.wfile.write(b"Not Found")

    def do_POST(self):
        # 读取请求体
        content_length = int(self.headers.get("Content-Length", 0))
        body = self.rfile.read(content_length)
        data = json.loads(body)

        self.send_response(201)
        self.send_header("Content-Type", "application/json")
        self.end_headers()
        response = json.dumps({"status": "ok", "received": data})
        self.wfile.write(response.encode("utf-8"))

# 启动服务器
server = HTTPServer(("localhost", 8000), MyHandler)
print("服务运行在 http://localhost:8000")
server.serve_forever()
```

### `urllib.request` —— 发起 HTTP 请求

```python
from urllib.request import urlopen, Request
from urllib.parse import urlencode, quote

# GET 请求
with urlopen("http://localhost:8000/api/tasks") as resp:
    data = resp.read().decode("utf-8")
    print(data)

# POST 请求
import json
req = Request(
    "http://localhost:8000/api/tasks",
    data=json.dumps({"title": "new task"}).encode("utf-8"),
    headers={"Content-Type": "application/json"},
    method="POST",
)
with urlopen(req) as resp:
    print(resp.status, resp.read().decode("utf-8"))
```

### `urllib.parse` —— URL 解析和处理

```python
from urllib.parse import urlparse, parse_qs, urlencode, quote

# 解析 URL
result = urlparse("http://example.com/path?key=value&a=1")
print(result.scheme)    # "http"
print(result.netloc)    # "example.com"
print(result.path)      # "/path"
print(parse_qs(result.query))  # {"key": ["value"], "a": ["1"]}

# 构建查询字符串
params = urlencode({"q": "python", "page": 1})
# "q=python&page=1"

# URL 编码
quote("hello world")  # "hello%20world"
```

## 5. 最小可运行例子

```python
# 服务器端 (server.py)
from http.server import HTTPServer, BaseHTTPRequestHandler

class Handler(BaseHTTPRequestHandler):
    def do_GET(self):
        self.send_response(200)
        self.end_headers()
        self.wfile.write(b"Hello from Python!")

HTTPServer(("localhost", 8000), Handler).serve_forever()
```

```python
# 客户端 (client.py)
from urllib.request import urlopen

with urlopen("http://localhost:8000") as resp:
    print(resp.read().decode())  # "Hello from Python!"
```

## 6. 实验任务

### 任务：Todo API 服务器

把实验 07 的 Todo 数据库版改造成 HTTP API 服务。

**API 设计**：

```text
GET    /api/tasks          → 获取所有任务
GET    /api/tasks/1        → 获取单个任务
POST   /api/tasks          → 创建任务
PUT    /api/tasks/1        → 更新任务
DELETE /api/tasks/1        → 删除任务
GET    /api/tasks?q=keyword → 搜索任务
```

写一个 `server.py`：

```bash
# 启动服务器
python server.py --port 8000

# 用 curl 测试
curl http://localhost:8000/api/tasks
curl -X POST http://localhost:8000/api/tasks \
  -H "Content-Type: application/json" \
  -d '{"title": "learn http"}'
curl http://localhost:8000/api/tasks/1
```

要求：
1. 支持 JSON 格式的请求和响应
2. 正确使用 HTTP 状态码（200 / 201 / 400 / 404 / 500）
3. 错误时返回有意义的 JSON 错误信息
4. 用 SQLite 持久化数据

## 7. 常见错误

| 错误 | 原因 |
|------|------|
| `Address already in use` | 端口被占用，换一个端口或关掉之前的进程 |
| `Connection refused` | 服务器没启动或端口不对 |
| `do_GET` 不生效 | 类名拼错或没正确继承 `BaseHTTPRequestHandler` |
| 中文乱码 | 没设置 `Content-Type` 的 charset 或没 `.encode("utf-8")` |
| POST 请求体为空 | 没读 `Content-Length` 头 |
