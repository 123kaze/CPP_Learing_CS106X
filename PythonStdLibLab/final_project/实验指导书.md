# 综合项目：命令行任务管理器 Todo CLI

## 1. 项目目标

把实验 01-10 学到的所有标准库组合起来，从 0 写出一个完整的命令行应用。

**这个项目做完，你就不是"看过标准库"，而是真的"用标准库做过应用"。**

---

## 2. 项目概览

### 涉及的标准库

| 库 | 用途 |
|----|------|
| `argparse` | 命令行参数解析 |
| `sqlite3` | 数据持久化 |
| `datetime` | 截止日期和时间 |
| `logging` | 日志记录 |
| `json` / `csv` | 导入导出 |
| `unittest` | 自动化测试 |
| `pathlib` | 文件路径管理 |

### 最终效果

```bash
# 添加任务
todo add "learn Python stdlib" --due 2026-07-20 --priority high

# 列出任务
todo list
# 输出:
# ⬜ #1 [high  ] learn Python stdlib    截止: 2026-07-20 (还有 11 天)

# 搜索
todo search python

# 完成
todo done 1

# 统计
todo stats

# 导入导出
todo export tasks.json
todo export tasks.csv
todo import tasks.csv

# 查看帮助
todo --help
```

```python
def main():
    parser = argparse.ArgumentParser(prog="todo")
    subparsers = parser.add_subparsers(dest="command")
    subparsers.add_parser("add")
    subparsers.add_parser("list")
    ...
    args = parser.parse_args()
    print(f"执行命令: {args.command}")
```


## 5. 验收标准

运行以下命令全部正常：

```bash
# 基本 CRUD
todo add "task 1" --priority high --due 2026-12-31
todo add "task 2" --priority medium
todo add "task 3" --priority low --due tomorrow
todo list                     # 看到 3 个任务
todo list --todo              # 看到 3 个未完成
todo done 1
todo list --done              # 看到 1 个已完成
todo remove 3
todo list                     # 看到 2 个任务

# 搜索
todo search "task"

# 统计
todo stats

# 导出导入
todo export tasks.json
todo export tasks.csv
todo import tasks.csv

# 帮助信息
todo --help
todo add --help

# 测试
python -m unittest test_todo.py -v
# 所有测试通过
```

## 6. 进阶方向

项目做完后，可以尝试：

1. **标签系统**：给任务打标签，按标签筛选
2. **配置文件**：用 `configparser` 管理配置（数据库路径、默认优先级等）
3. **Web 接口**：参考实验 09，给 Todo 加上 HTTP API
4. **多用户支持**：每个用户有自己的任务列表
5. **TUI 界面**：用 `curses` 或 `rich` 做终端界面
6. **定时提醒**：用后台线程检查即将到期的任务
