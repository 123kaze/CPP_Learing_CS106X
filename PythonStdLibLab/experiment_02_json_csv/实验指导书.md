## 3. 核心库 & 常用 API

### `json` —— JSON 读写

```python
import json

# Python → JSON 字符串
json.dumps(data)               # 返回字符串
json.dumps(data, indent=2)     # 格式化输出
json.dumps(data, ensure_ascii=False)  # 保留中文

# Python → JSON 文件
with open("out.json", "w", encoding="utf-8") as f:
    json.dump(data, f, indent=2, ensure_ascii=False)

# JSON 字符串 → Python
data = json.loads(json_string)

# JSON 文件 → Python
with open("in.json", "r", encoding="utf-8") as f:
    data = json.load(f)
```

**JSON 类型映射**：
| Python | JSON |
|--------|------|
| dict | object |
| list | array |
| str | string |
| int/float | number |
| True/False | boolean |
| None | null |

### `csv` —— CSV 读写

```python
import csv

# 读取
with open("data.csv", "r", newline="", encoding="utf-8") as f:
    reader = csv.DictReader(f)       # 每行是 dict（推荐）
    # reader = csv.reader(f)         # 每行是 list
    for row in reader:
        print(row["name"], row["age"])

# 写入
with open("out.csv", "w", newline="", encoding="utf-8") as f:
    writer = csv.DictWriter(f, fieldnames=["name", "age"])
    writer.writeheader()
    writer.writerow({"name": "Alice", "age": 20})
    writer.writerows([
        {"name": "Bob", "age": 22},
        {"name": "Carol", "age": 21},
    ])
```

### `configparser` —— INI 配置文件

```python
import configparser

# 读取
config = configparser.ConfigParser()
config.read("config.ini")
value = config.get("section_name", "key_name")      # 字符串
value = config.getint("section_name", "port")        # 整数
value = config.getboolean("section_name", "debug")   # 布尔

# 写入
config["database"] = {"host": "localhost", "port": "5432"}
with open("config.ini", "w") as f:
    config.write(f)
```

**config.ini 格式**：
```ini
[output]
path = ./output
format = json

[input]
path = ./data
encoding = utf-8
```

## 4. 最小可运行例子

```python
import json, csv
from pathlib import Path

# 读取 CSV，转成 JSON
students = []
with open("students.csv", "r", newline="", encoding="utf-8") as f:
    for row in csv.DictReader(f):
        students.append(row)

Path("students.json").write_text(
    json.dumps(students, indent=2, ensure_ascii=False),
    encoding="utf-8"
)
print(f"转换完成：{len(students)} 条记录")
```

## 5. 实验任务

### 任务：格式转换器

写一个 `convert.py`，支持以下转换：

```bash
# CSV → JSON
python convert.py students.csv --to json --output students.json

# JSON → CSV
python convert.py students.json --to csv --output students.csv

# 从配置文件读取输入输出路径
python convert.py --config config.ini
```

要求：
1. 自动检测输入文件格式（根据后缀）
2. 支持 CSV → JSON 和 JSON → CSV 双向转换
3. 支持从 `config.ini` 读取配置
4. 处理文件不存在、格式错误等异常

### 进阶挑战

- 支持 `--pretty` 参数控制 JSON 是否格式化
- 支持筛选（只输出某些列）
- 处理 CSV 中的编码问题（尝试 utf-8、gbk 等）

## 6. 常见错误

| 错误 | 原因 |
|------|------|
| `json.decoder.JSONDecodeError` | JSON 格式不正确 |
| 中文变成 `\uXXXX` | 没用 `ensure_ascii=False` |
| CSV 有空行 | 打开文件时没加 `newline=""` |
| KeyError 读 CSV | `DictReader` 的列名没写对 |
| `configparser.NoSectionError` | 配置文件中 section 不存在 |
