## 3. 核心 API

### `unittest` 基本结构

```python
import unittest

# 测试类继承 unittest.TestCase
class TestMyFunction(unittest.TestCase):

    # setUp 在每个测试方法前执行
    def setUp(self):
        self.data = [1, 2, 3]

    # tearDown 在每个测试方法后执行
    def tearDown(self):
        pass

    # 测试方法必须以 test_ 开头
    def test_addition(self):
        result = 1 + 1
        self.assertEqual(result, 2)          # 相等
        self.assertNotEqual(result, 3)       # 不等

    def test_list_operations(self):
        self.assertIn(2, self.data)          # 包含
        self.assertEqual(len(self.data), 3)  # 长度

    def test_raises(self):
        with self.assertRaises(ZeroDivisionError):
            1 / 0                             # 期望抛出异常

    def test_float(self):
        self.assertAlmostEqual(0.1 + 0.2, 0.3, places=7)  # 浮点近似

# 运行测试
if __name__ == "__main__":
    unittest.main()
```

### 常用断言方法

```python
self.assertEqual(a, b)               # a == b
self.assertNotEqual(a, b)            # a != b
self.assertTrue(x)                   # bool(x) is True
self.assertFalse(x)                  # bool(x) is False
self.assertIs(a, b)                  # a is b
self.assertIsNone(x)                 # x is None
self.assertIsNotNone(x)              # x is not None
self.assertIn(a, b)                  # a in b
self.assertNotIn(a, b)               # a not in b
self.assertRaises(Exc, func, *args)  # func(*args) 抛出 Exc
self.assertAlmostEqual(a, b)         # 浮点近似
```

### 用 `setUp` 准备测试数据

```python
class TestTodo(unittest.TestCase):
    def setUp(self):
        """每个测试方法前执行：创建临时的 Todo 数据库"""
        self.db_path = ":memory:"  # SQLite 内存数据库，测试完就消失！
        self.conn = sqlite3.connect(self.db_path)
        self.conn.row_factory = sqlite3.Row
        self.conn.execute("""
            CREATE TABLE tasks (
                id INTEGER PRIMARY KEY,
                title TEXT,
                done INTEGER DEFAULT 0
            )
        """)

    def tearDown(self):
        """每个测试方法后执行：关闭连接"""
        self.conn.close()

    def test_add_task(self):
        self.conn.execute("INSERT INTO tasks (title) VALUES (?)", ("test",))
        self.conn.commit()
        row = self.conn.execute("SELECT * FROM tasks").fetchone()
        self.assertEqual(row["title"], "test")
        self.assertEqual(row["done"], 0)
```

## 5. 什么值得测？

```text
✅ 测核心逻辑：添加任务、完成任务、搜索
✅ 测边界条件：空输入、超长输入、负数 ID
✅ 测错误处理：不存在的任务、非法日期
✅ 测数据不变性：做完操作后数据是否一致

❌ 不测标准库的行为（比如不测 sqlite3 能不能 INSERT）
❌ 不测 trivially 正确的代码（比如 getter/setter）
```

## 6. 最小可运行例子

```python
import unittest

def fibonacci(n):
    """返回第 n 个斐波那契数（从 0 开始）"""
    if n < 0:
        raise ValueError("n must be >= 0")
    if n <= 1:
        return n
    return fibonacci(n - 1) + fibonacci(n - 2)

class TestFibonacci(unittest.TestCase):
    def test_base_cases(self):
        self.assertEqual(fibonacci(0), 0)
        self.assertEqual(fibonacci(1), 1)

    def test_normal_cases(self):
        self.assertEqual(fibonacci(5), 5)
        self.assertEqual(fibonacci(10), 55)

    def test_invalid_input(self):
        with self.assertRaises(ValueError):
            fibonacci(-1)

if __name__ == "__main__":
    unittest.main()
```

## 8. 常见错误

| 错误 | 原因 |
|------|------|
| 测试方法没以 `test_` 开头 | `unittest` 不会自动发现 |
| `setUp` 拼成 `setup` | 不会报错，但不会自动执行 |
| 测试之间有依赖 | 每个测试应该独立，顺序不应该影响结果 |
| 测试数据污染 | 没在 `tearDown` 清理，影响后续测试 |
| 只测 happy path | 也要测边界条件和错误情况 |
