## 2. 函数题：C++ 面向对象必会清单

PTA 函数题的形式：**裁判程序已经给了 `main` 和部分类声明，你只提交「请在这里填写答案」的部分**。
- 不要再写 `main`，不要重复定义题目已经给出的类。
- 题目给了类声明 → 你写类外实现 `返回类型 类名::函数名(...) { }`。
- 题目只给了 `main` → 你要写完整的类（参考 6-9、6-11、6-13）。
- 输出要和样例**逐字符**一致（包括题目里的拼写错误，比如 6-12 的 `desturct`）。

### 2.1 类的骨架（背下来）

```cpp
class Student {
private:
    string name;
    int score;
    static int count;                 // 静态成员：所有对象共享
public:
    Student() : name(""), score(0) { count++; }                    // 默认构造
    Student(const string& n, int s) : name(n), score(s) { count++; } // 带参构造
    Student(const Student& o) : name(o.name), score(o.score) { count++; } // 拷贝构造
    ~Student() { count--; }                                         // 析构

    string getName() const { return name; }   // const 成员函数：不修改对象
    void setScore(int s) { this->score = s; }
    static int getCount() { return count; }   // 静态成员函数：没有 this，只能访问静态成员
};
int Student::count = 0;   // 静态成员必须在类外定义（const int 整型或 C++17 inline 除外）
```

### 2.2 构造 / 析构顺序（6-11、6-12 类题型的核心）

规则：
1. **构造**：先基类 → 再成员对象（按**类内声明顺序**，不看初始化列表顺序）→ 最后自己的构造函数体。
2. **析构**：和构造完全相反。
3. 多个局部对象：先构造的后析构；全局/静态对象在 main 结束后析构。

```cpp
struct A { A(){cout<<"A ";} ~A(){cout<<"~A ";} };
struct B { B(){cout<<"B ";} ~B(){cout<<"~B ";} };
struct M { M(){cout<<"M ";} ~M(){cout<<"~M ";} };
struct C : public A { M m; B b; C(){cout<<"C ";} ~C(){cout<<"~C ";} };
// { C c; } 输出：A M B C ~C ~B ~M ~A     （已实测）
```

**拷贝构造什么时候被调用**（常考！）：
```cpp
T a;          // T()
T b = a;      // 拷贝构造（不是赋值！）
T b2(a);      // 拷贝构造
T c; c = a;   // T() + operator=（赋值，不是拷贝构造）
void f(T x);  f(a);        // 按值传参 → 拷贝构造，函数结束时 x 析构
void g(const T& x); g(a);  // 按引用 → 不拷贝
// 实测输出：T() T(copy) T() op= T(copy) ~T | ~T ~T ~T
```
函数按值返回对象时，编译器通常会做返回值优化（RVO）省掉拷贝——如果题目样例输出里少了一次 copy，就是这个原因。

**组合类的构造函数**（6-4、6-12）：成员对象没有默认构造时，**必须**在初始化列表里构造它：
```cpp
Club::Club(string n1, int y, string n2, int wr) : name(n1), c(n2, wr), year(y) {}
```

### 2.3 继承与多态（6-1、6-13）

```cpp
class Shape {
protected:                       // 子类能访问，外部不能
    string name;
public:
    Shape(const string& n) : name(n) {}
    virtual double area() const = 0;        // 纯虚函数 → Shape 是抽象类，不能实例化
    virtual void show() const { cout << name << " " << area() << endl; }
    virtual ~Shape() {}                      // 基类析构一定要 virtual
};

class Circle : public Shape {
    double r;
public:
    Circle(double r) : Shape("Circle"), r(r) {}       // 调用基类构造
    double area() const override { return 3.14159 * r * r; }
};

Shape* p = new Circle(1.0);
p->show();      // 走虚函数 → 调 Circle::area
delete p;       // 因为虚析构，先 ~Circle 再 ~Shape
```

要点：
- **基类指针/引用 + virtual** 才有多态；不是 virtual 的函数按**指针类型**调用（实测：`Base* p = new Der; p->g();` 非虚函数调用的是 `Base::g`）。
- 基类析构不是 virtual 时，`delete 基类指针` 只会调基类析构 → 析构输出会少一行。
- 子类构造必须在初始化列表里调用基类构造（基类没有默认构造时）。
- 继承方式：`public` 继承保持访问级别；`private` 成员子类不能直接访问，要用 `protected` 或 getter。
- 子类同名函数会**隐藏**基类的同名函数；想调基类版本写 `Base::func()`。
- 菱形继承：`class B : virtual public A`（虚继承），A 只有一份。了解即可。

### 2.4 运算符重载（6-5、6-14）

```cpp
class Complex {
    double re, im;
public:
    Complex(double r = 0, double i = 0) : re(r), im(i) {}

    // 成员形式：左操作数是 *this
    Complex operator+(const Complex& o) const { return Complex(re + o.re, im + o.im); }
    Complex operator-(const Complex& o) const { return Complex(re - o.re, im - o.im); }
    Complex& operator+=(const Complex& o) { re += o.re; im += o.im; return *this; }
    bool operator==(const Complex& o) const { return re == o.re && im == o.im; }

    Complex& operator++() { ++re; return *this; }                     // 前置 ++a
    Complex operator++(int) { Complex t = *this; ++re; return t; }    // 后置 a++（int 是占位）

    // 友元形式：左操作数是流，所以必须写成非成员
    friend ostream& operator<<(ostream& os, const Complex& c) {
        os << c.re;
        if (c.im >= 0) os << "+";
        os << c.im << "i";
        return os;                 // 必须返回流，才能连续 cout << a << b
    }
    friend istream& operator>>(istream& is, Complex& c) {   // 读入不能加 const
        is >> c.re >> c.im;
        return is;
    }
    friend Complex operator*(double k, const Complex& c) {  // 2 * c 这种左边不是对象的
        return Complex(k * c.re, k * c.im);
    }
};
```

**有指针成员的类：深拷贝三件套**（拷贝构造 + 赋值运算符 + 析构）：
```cpp
class MyString {
    char* p;
public:
    MyString(const char* s = "") { p = new char[strlen(s) + 1]; strcpy(p, s); }
    MyString(const MyString& o) { p = new char[strlen(o.p) + 1]; strcpy(p, o.p); }
    MyString& operator=(const MyString& o) {
        if (this != &o) {                  // 防自赋值
            delete[] p;
            p = new char[strlen(o.p) + 1];
            strcpy(p, o.p);
        }
        return *this;
    }
    ~MyString() { delete[] p; }            // new[] 对应 delete[]
    char& operator[](int i) { return p[i]; }
};
```

### 2.5 模板（6-6）

```cpp
// 函数模板
template <class T>
T myMax(T a, T b) { return a > b ? a : b; }

// 类模板
template <class T>
class Stack {
    vector<T> a;
public:
    void push(const T& x) { a.push_back(x); }
    void pop() { a.pop_back(); }
    T top() const;
    bool empty() const { return a.empty(); }

```

### 2.6 链表与指针（6-2、6-10）

```cpp
struct Node { int val; Node* next; };

Node* insertSorted(Node* head, Node* node) {   // 有序插入，返回新头
    if (head == NULL || node->val < head->val) { node->next = head; return node; }
    Node* p = head;
    while (p->next != NULL && p->next->val < node->val) p = p->next;
    node->next = p->next;
    p->next = node;
    return head;
}
Node* reverse(Node* head) {
    Node* prev = NULL;
    while (head) { Node* nx = head->next; head->next = prev; prev = head; head = nx; }
    return prev;
}
```
- 解引用之前先判空：`p != NULL && p->next ...`（短路求值的顺序不能反）。
- `new` 对应 `delete`，`new T[n]` 对应 `delete[]`。

### 2.7 其它零碎但会考的

- `this` 是指针：`this->x`，返回自身用 `return *this;`
- `const` 对象只能调用 `const` 成员函数。
- 引用传参 `T&` 能改实参；`const T&` 能接临时对象。
- 默认参数只写在声明里，类外定义时不要再写一遍。
- `enum CPU_Rank { P1 = 1, P2, P3 };` 输出时 `cout << rank` 输出的是数字；int 转 enum 用 `static_cast<CPU_Rank>(x)`。
- `struct` 默认 public，`class` 默认 private。
- 友元函数不是成员，类外定义时不加 `类名::`。
- 用到 `string` 就要 `#include <string>` 和 `using namespace std;`（6-1 单独编译报错就是因为没写；裁判程序一般会给，没给就自己补）。

### 2.8 函数题自测：先手推输出，再运行对照

把 `6-11`、`6-12` 的 main 拿出来，**不运行，先在纸上写出完整输出**，然后再运行对照。能一次写对就说明构造/析构顺序过关了。

### 3.4 "复杂度高只能 C++" 的判断标准

| 情况 | 用 C++ |
|---|---|
| n ≥ 1e5 且 O(n log n) | Python 有可能超时，直接 C++ |
| 总运算量 ≥ 1e7 | C++ |
| 指数级搜索 + 剪枝（62、42、47） | C++ |
| 递归深度可能 ≥ 1e4 | C++（或改迭代）；Python 要 `setrecursionlimit` 也不保险 |

## 4. C++ 编程题模板（Python → C++ 翻译手册）

### 4.1 开头 + 输入输出

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    // 关了同步以后不要再混用 scanf/printf 和 cin/cout
}
```

| Python | C++ |
|---|---|
| `input().split()` | `cin >> a >> b;` |
| `input()` 整行（含空格） | `getline(cin, s);` —— **前面用过 `cin >>` 的话先 `cin.ignore();` 或写 `getline(cin >> ws, s)`** |
| 读到 EOF | `while (cin >> x) { ... }` |
| `f'{x:.2f}'` | `printf("%.2f\n", x);` 或 `cout << fixed << setprecision(2) << x;` |
| `f'{x:05d}'` | `printf("%05d", x);` 或 `cout << setw(5) << setfill('0') << x;` |
| `print(*a)` | `for (int i = 0; i < n; i++) cout << (i ? " " : "") << a[i]; cout << "\n";` |
| `s.split(':')` | `sscanf(s.c_str(), "%d:%d:%d", &h, &m, &sec);` 或 `stoi(s.substr(0,2))` |
| `int(s)` / `str(x)` | `stoi(s)` / `stoll(s)` / `to_string(x)` |
| `s[::-1]` | `reverse(s.begin(), s.end());` |
| `x in s`（子串） | `s.find(t) != string::npos` |
| `s.lower()` | `for (auto& c : s) c = tolower(c);` |

**PTA 格式错误**：行末多空格、少换行都会判错。默认按"数字间一个空格，行首尾无多余空格"输出。

### 4.2 容器对照

| Python | C++ |
|---|---|
| `list` | `vector<int> a(n, 0);` 二维：`vector<vector<ll>> dp(n+1, vector<ll>(m+1, 0));` |
| `dict` | `unordered_map<string,int>`；要按 key 有序遍历用 `map` |
| `defaultdict(list)` | `unordered_map<int, vector<int>> g;`（`g[x]` 不存在时自动创建空 vector） |
| `set` | `unordered_set` / `set`（有序，能 `lower_bound`） |
| `deque` | `deque<int>` / `queue<int>` |
| `heapq`（小根堆） | `priority_queue<int, vector<int>, greater<int>> pq;` |
| `Counter` | `map<int,int> cnt; cnt[x]++;` |
| `x in d` | `d.count(x)` —— **不要用 `d[x]` 来判断，会插入一个默认值** |
| `sorted(a, key=...)` | `sort(a.begin(), a.end(), [](const T& x, const T& y){ return ...; });` |
| `bisect_left` | `lower_bound(a.begin(), a.end(), x) - a.begin()` |
| tuple 比较 | `tie(a.x, a.y) < tie(b.x, b.y)`（66 题用过） |
| `@cache` | `vector<vector<ll>> memo(n, vector<ll>(m+1, -1));` + `ll& res = memo[i][j];` |

多关键字排序：
```cpp
struct Stu { string id; int score, age; };
sort(v.begin(), v.end(), [](const Stu& a, const Stu& b) {
    if (a.score != b.score) return a.score > b.score;   // 分数降序
    return a.id < b.id;                                  // 学号升序
});
```
**比较函数必须是严格弱序**：相等时要返回 `false`，写成 `<=` 可能直接段错误。

### 4.3 关键模板

**凑硬币字典序最小（63 的正确写法，已实测）** —— O(n·m)：
```cpp
sort(v.begin(), v.end());
// can[i][s]：只用 v[i..n-1] 能否恰好凑出 s
vector<vector<char>> can(n + 1, vector<char>(m + 1, 0));
can[n][0] = 1;
for (int i = n - 1; i >= 0; i--)
    for (int s = 0; s <= m; s++)
        can[i][s] = can[i + 1][s] || (s >= v[i] && can[i + 1][s - v[i]]);
if (!can[0][m]) { cout << "No Solution\n"; return 0; }
vector<int> ans;
int s = m;
for (int i = 0; i < n && s > 0; i++)   // 从小到大，能拿就拿 → 字典序最小
    if (s >= v[i] && can[i + 1][s - v[i]]) { ans.push_back(v[i]); s -= v[i]; }
```
这个"**先从后往前算可行性，再从前往后贪心构造**"的套路，所有"输出字典序最小方案"的 DP 都能用。

**0/1 背包（一维，倒序）/ 完全背包（正序）**：
```cpp
for (int i = 0; i < n; i++)
    for (int j = W; j >= w[i]; j--)        // 0/1：倒序
        dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
// 完全背包：for (int j = w[i]; j <= W; j++)
```

**树：找根 + BFS 求最深结点（44 的正确写法）**：
```cpp
int root = 1;
while (root <= n && indeg[root] != 0) root++;
queue<int> q; q.push(root);
int last = root;
while (!q.empty()) {
    int u = q.front(); q.pop();
    last = u;                    // BFS 最后出队的就是最深的
    for (int v : g[u]) q.push(v);
}
cout << last << "\n";
```

**中序 + 后序建树（49）**：用 `unordered_map<int,int> pos` 存中序下标，避免每次 `find` 是 O(n)。

**并查集**：
```cpp
vector<int> fa(n + 1);
iota(fa.begin(), fa.end(), 0);
function<int(int)> find = [&](int x) { return fa[x] == x ? x : fa[x] = find(fa[x]); };
auto unite = [&](int a, int b) { fa[find(a)] = find(b); };
```

**Dijkstra（堆优化）**：
```cpp
vector<ll> dist(n, LLONG_MAX);
priority_queue<pair<ll,int>, vector<pair<ll,int>>, greater<>> pq;
dist[s] = 0; pq.push({0, s});
while (!pq.empty()) {
    auto [d, u] = pq.top(); pq.pop();
    if (d > dist[u]) continue;
    for (auto [v, w] : g[u])
        if (dist[u] + w < dist[v]) { dist[v] = dist[u] + w; pq.push({dist[v], v}); }
}
```

**拓扑排序**：入度为 0 的入队，出队时邻居入度减一；最后出队数 < n 说明有环。

**时间字符串转秒（46、59）**：
```cpp
int h, m, s;
sscanf(str.c_str(), "%d:%d:%d", &h, &m, &s);
int t = h * 3600 + m * 60 + s;
```

### 4.4 C++ 特有的坑

- **溢出**：乘法、累加、计数类 DP（64）一律 `long long`；`1 << 40` 要写成 `1LL << 40`。
- `int` 和 `size()` 比较：`for (int i = 0; i < (int)v.size(); i++)`；`v.size() - 1` 在空 vector 上会变成一个超大数。
- 数组开在 `main` 里太大会爆栈 → 大数组开全局或用 `vector`。
- `memset` 只能设 `0` 和 `-1`；其他值用 `fill` 或 `assign`。
- 浮点比较用 `fabs(a - b) < 1e-8`；四舍五入输出交给 `printf("%.2f")`。
- `/` 对负数是向 0 取整，`%` 结果可能是负数。
- 递归 DFS 回溯：`visited` 标记和 `path.push_back` 要成对撤销（62 写得对，保持住）。
- 全局变量多组数据时要重置。

## 6. 本地环境（Mac）

Mac 自带的 `g++` 实际上是 clang，没有 `bits/stdc++.h`（`44、46、48、62、64、65.di、66、67.matrix` 本地都编译不过，但 PTA 上没问题）。两种解决办法：

```bash
# 办法一：装真正的 GCC
brew install gcc            # 然后用 g++-14 (或 g++-15) 编译

# 办法二：自己建一个 bits/stdc++.h，编译时加 -I
mkdir -p ~/include/bits
# 在 ~/include/bits/stdc++.h 里 #include 常用头文件（iostream/vector/map/...）
g++ -std=c++17 -I ~/include a.cpp -o a
```

建议编译时加上 `-Wall`：这次的 `-Wreorder`、空语句 `nextNode[node];`、没写 return 这几个问题，都能靠警告提前发现。

```bash
g++ -std=c++17 -Wall -O2 a.cpp -o a && ./a < in.txt
```
