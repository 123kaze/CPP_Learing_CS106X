裁判程序已经给了 main 和部分类声明，你只提交「请在这里填写答案」的那部分。

提交前四问：

② 构造 / 析构顺序 + 拷贝构造的调用时机（6-11、6-12 的核心）
构造：基类 → 成员对象（按声明顺序）→ 自己的函数体。析构：完全相反。局部对象先构造的后析构。
函数按值返回对象时，编译器通常会省掉拷贝（RVO）。如果样例输出里少了一次 copy，就是这个原因。

③ 继承与多态（6-1、6-13）
  • 基类指针 + virtual 才有多态；非虚函数按指针类型调用（实测 Base* p = new Der; p->g(); 调的是 Base::g）。
  • 基类析构不是 virtual → delete 基类指针 只调基类析构，输出会少一行。
  • 子类同名函数会隐藏基类版本；要调基类的写 Base::func()。
  • private 成员子类不能直接访问 → 用 protected 或 getter。
  • 菱形继承用 class B : virtual public A，了解即可。
④ 运算符重载（6-5、6-14）
⑤ 深拷贝三件套（类里有指针成员时）
⑥ 模板（6-6）

自己的函数和 std 里的重名（6-6 的 sort），参数类型不同一般不冲突；报 ambiguous 就写 ::sort(...)。

⑦ 链表与指针（6-2、6-10）

先判空再解引用：p != NULL && p->next，短路的顺序不能反。

⑧ 零碎但会考的
  • this 是指针：this->x；返回自身写 return *this;
  • const 对象只能调用 const 成员函数。
  • T& 能改实参；const T& 能接临时对象。
  • 默认参数只写在声明里，类外定义时不要再写。
  • enum R { P1 = 1, P2 }; 用 cout 输出是数字；int 转 enum 用 static_cast<R>(x)。
  • struct 默认 public，class 默认 private。
  • 友元函数不是成员，类外定义时不加 类名::。
  • new 对应 delete，new T[n] 对应 delete[]。

C++ 特有的坑

  • 溢出：乘积、累加、计数类 DP 一律 long long；1 << 40 要写 1LL << 40。
  • v.size() - 1 在空 vector 上是一个超大数 → 先转 (int)v.size()。
  • 大数组开在 main 里会爆栈 → 开全局或者用 vector。
  • memset 只能设 0 和 -1，其他值用 fill / assign。
  • 浮点比较用 fabs(a - b) < 1e-8。
  • 负数 / 向 0 取整，% 结果可能是负数。
  • C++ 的 && || 也会短路：递归求值时（比如 50 题）先把左右两边都算出来再合并，不然读输入的下标会错位。
  • 多组数据时，全局变量记得重置。
