## 🎯 考试概述

**PAT 甲等**是浙江大学计算机程序设计能力考试的最高等级，主要考察：
- 复杂问题的分析与建模能力
- 数据结构和算法的综合运用
- 编程实现与调试能力
- 时间和空间复杂度优化

**考试形式**：
- 4道编程题，满分100分
- 时间限制：3小时
- 语言支持：C/C++/Java/Python
- 在线评测，即时反馈

**分数目标**：
- 90+ 分：优秀（有望获得浙江大学复试优势）
- 80-89 分：良好
- 70-79 分：及格

## 🧠 核心考点分析（按重要性排序）

### 1. 数据结构（占比约35%）
| 数据结构 | 考察频率 | 关键点 |
|---------|---------|-------|
| **并查集** | ⭐⭐⭐⭐⭐ | 必考！掌握路径压缩和按秩合并 |
| **堆/优先队列** | ⭐⭐⭐⭐⭐ | Top K、中位数、哈夫曼编码 |
| **平衡二叉树** | ⭐⭐⭐⭐ | AVL树插入旋转（PAT最爱考） |
| **树状数组/线段树** | ⭐⭐⭐ | 区间查询、更新操作 |
| **哈希表** | ⭐⭐⭐⭐ | 复杂键设计（`map<vector<int>, int>`） |

### 2. 图算法（占比约25%）
| 算法 | 考察频率 | 关键点 |
|------|---------|-------|
| **Dijkstra** | ⭐⭐⭐⭐⭐ | 必须掌握堆优化版本 |
| **最小生成树** | ⭐⭐⭐⭐ | Prim、Kruskal算法 |
| **拓扑排序** | ⭐⭐⭐⭐ | 课程安排、任务调度 |
| **连通分量** | ⭐⭐⭐ | 强连通、割点、桥 |
| **欧拉/哈密顿路径** | ⭐⭐ | 偶尔考察 |

### 3. 动态规划（占比约20%）
| 类型 | 考察频率 | 关键点 |
|------|---------|-------|
| **背包问题** | ⭐⭐⭐⭐ | 01背包、完全背包 |
| **区间 DP** | ⭐⭐⭐⭐ | 矩阵链乘、石子合并 |
| **树形 DP** | ⭐⭐⭐ | 树的最大独立集、直径 |
| **状态压缩 DP** | ⭐⭐ | 旅行商问题变种 |

### 4. 字符串处理（占比约10%）
| 算法 | 考察频率 | 关键点 |
|------|---------|-------|
| **KMP算法** | ⭐⭐⭐ | 模式匹配 |
| **Trie树** | ⭐⭐⭐ | 前缀查找、自动补全 |
| **复杂字符串解析** | ⭐⭐⭐⭐ | 正则表达式替代 |

### 5. 数学与模拟（占比约10%）
| 类型 | 考察频率 | 关键点 |
|------|---------|-------|
| **大整数运算** | ⭐⭐⭐ | Python轻松，C++需实现 |

## 💡 考试技巧

### 1. 时间分配策略
- **前30分钟**：快速浏览4题，评估难度
- **第1小时**：完成最简单2题（确保全对）
- **第2小时**：主攻中等难度1题
- **最后1小时**：尝试难题 + 检查调试

### 2. 输入输出优化
```python
# Python快速读取
import sys
input = sys.stdin.readline

# 读取整数
n = int(input())

# 读取一行整数
arr = list(map(int, input().split()))

# 读取多行
data = [input().strip() for _ in range(n)]
```

### 3. 调试技巧
- 使用`print`调试，提交前删除
- 准备边界测试用例（0、1、最大值）
- 利用PAT的样例得分功能

### 4. 分数策略
- **前两题必须全对**（40分）
- **第三题争取高分**（25-30分）
- **第四题尽力而为**（10-20分）
- 总分目标：80+（前两题全对 + 第三题高分）
