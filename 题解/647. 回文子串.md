# 647. 回文子串 🔄

## 题目

给定字符串 `s`，统计其中**回文子串**的数量（不同位置的相同子串算多个）。

```
输入: s = "aaa"
输出: 6
解释: "a","a","a","aa","aa","aaa"
```

## 思路 —— 区间 DP

判断 `s[i:j+1]` 是否回文 → 剥洋葱 🧅

```
s[i] == s[j]  →  看 s[i+1:j] 是否回文
s[i] != s[j]  →  不是回文
```

### 状态定义

`dfs(i, j)` = `s[i:j+1]` 是否是回文串

### 递推公式

```
dfs(i, j) = True             当 i >= j        （单字符/空字符串）
dfs(i, j) = False            当 s[i] != s[j]
dfs(i, j) = dfs(i+1, j-1)   当 s[i] == s[j]
```

## 代码

```python
from functools import lru_cache

class Solution:
    def countSubstrings(self, s: str) -> int:
        n = len(s)

        @lru_cache(maxsize=None)
        def dfs(i: int, j: int) -> bool:
            """s[i:j+1] 是否回文"""
            if i >= j:
                return True
            if s[i] != s[j]:
                return False
            return dfs(i + 1, j - 1)

        res = 0
        for j in range(n):
            for i in range(j + 1):  # 枚举所有子串
                if dfs(i, j):
                    res += 1
        return res
```

## 复杂度

| | 时间 | 空间 |
|------|------|------|
| 复杂度 | O(n²) | O(n²) |

枚举 `n²` 个子串，每个 O(1) 判断（记忆化后）。

## 优化：中心扩展法 🎯

```python
# 每个中心向两边扩展，O(n²) 时间，O(1) 空间
res = 0
for i in range(n):
    # 奇数长度回文（单个中心）
    l = r = i
    while l >= 0 and r < n and s[l] == s[r]:
        res += 1; l -= 1; r += 1
    # 偶数长度回文（两个中心）
    l, r = i, i + 1
    while l >= 0 and r < n and s[l] == s[r]:
        res += 1; l -= 1; r += 1
```

> 中心扩展法不需要 O(n²) 空间，更推荐面试时用！
