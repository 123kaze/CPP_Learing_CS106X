# 337. 打家劫舍 III 🏠🌲

## 题目

小偷在二叉树结构的房屋中行窃。**相邻节点（父子关系）不能同时偷**。求最大金额。

```
    3
   / \
  2   3
   \   \
    3   1
→ 偷 3+3+1 = 7
```

## 思路 —— 树形 DP

每个节点有两种状态：

- `[偷, 不偷]` = `[yes, no]`

### 状态转移

设 `dfs(node)` 返回 `(yes, no)`：

| 状态 | 含义 | 计算方式 |
|------|------|----------|
| `yes` | 偷当前节点 | `val + nleft + nright` ← **左右都不偷** |
| `no` | 不偷当前节点 | `max(left) + max(right)` ← **左右随便** |

> 🔑 **关键**：偷了当前节点，左右孩子必须"不偷"；不偷当前节点，左右孩子可以偷也可以不偷，各取最大。

### 递推公式

```
yes = node.val + dfs(node.left).no + dfs(node.right).no
no  = max(dfs(node.left).yes, dfs(node.left).no)
    + max(dfs(node.right).yes, dfs(node.right).no)
```

## 代码

```python
from functools import lru_cache
from typing import Optional

class Solution:
    def rob(self, root: Optional[TreeNode]) -> int:
        @lru_cache(None)
        def dfs(node) -> tuple:
            if not node:
                return (0, 0)  # (偷, 不偷)

            left_yes, left_no = dfs(node.left)
            right_yes, right_no = dfs(node.right)

            # 偷当前 → 左右必须不偷
            cur_yes = left_no + right_no + node.val

            # 不偷当前 → 左右各自取最大
            cur_no = max(left_yes + right_yes,
                         left_yes + right_no,
                         left_no + right_yes,
                         left_no + right_no)

            return (cur_yes, cur_no)

        yes, no = dfs(root)
        return max(yes, no)
```

> 💡 `cur_no` 可简化为 `max(left_yes, left_no) + max(right_yes, right_no)`，四种组合的最大值就是这个。

## 复杂度

| | 时间 | 空间 |
|------|------|------|
| 复杂度 | O(n) | O(n) |

每个节点只访问一次，`lru_cache` 保证不重复计算。
