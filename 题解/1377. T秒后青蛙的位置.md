# 1377. T 秒后青蛙的位置 🐸

## 题目

给定一棵 `n` 个节点的**无向树**（节点编号 `1~n`），青蛙从节点 `1` 开始跳。每秒钟青蛙**等概率地**跳到它没有访问过的邻居节点。不能原地跳。

给定时间 `t` 和目标节点 `target`，求青蛙在 `t` 秒时位于 `target` 的概率。

## 思路 —— DFS + 概率乘积

这本质是一个**树上 DFS + 概率传递**的问题。

- 从根节点 `1` 出发概率为 `1.0`
- 每走一步，概率 **÷ 未访问的邻居数**（等概率选择）
- 到 `t` 秒或叶子节点时停止

### 三种情况

| 情况 | 结果 |
|------|------|
| `time > t` | 超时，不可能到达终点 → `0.0` |
| `cur == target` 且 (`子节点为空` 或 `time == t`) | 刚好到 target，或在 target 上停留 → `prob` |
| `cur == target` 但 `time < t` 且有子节点 | 还能跳走，无法停留 → `0.0` |

> 🔑 **关键理解**：青蛙到了 target 后如果还有子节点可跳，就一定会跳走！只有叶子节点才能"停留"。

## 代码

```python
from collections import defaultdict
from typing import List

class Solution:
    def frogPosition(self, n: int, edges: List[List[int]], t: int, target: int) -> float:
        # 邻接表建图
        ke = defaultdict(list)
        for u, v in edges:
            ke[u].append(v)
            ke[v].append(u)

        def dfs(time: int, cur: int, parent: int, prob: float) -> float:
            if time > t:
                return 0.0

            # 获取所有未访问的子节点
            children = [c for c in ke[cur] if c != parent]
            num = len(children)

            # 到达目标节点
            if cur == target:
                # 叶子节点 或 时间刚好到 → 停留
                if num == 0 or t == time:
                    return prob
                else:
                    return 0.0  # 还能走，不能停

            if num == 0:
                return 0.0

            # 等概率走向每个子节点
            for child in children:
                result = dfs(time + 1, child, cur, prob / num)
                if result > 0:
                    return result

            return 0.0

        return dfs(0, 1, 1, 1.0)
```

## 复杂度

| | 时间 | 空间 |
|------|------|------|
| 复杂度 | O(n) | O(n) |

每个节点只访问一次，树遍历标准复杂度。

## 易错点 ⚠️

1. **无向树用 `parent` 避免回头**，不能简单用 `visited` 数组（树天然无环，父节点就够了）
2. **`prob / num`** 不是 `prob * (1/num)`，注意浮点运算
3. **target 是叶子节点**时可以提前超时停留（>t 秒后还在原地），但非叶子不行
